## Description
This project solves five beginner-level coding problems using JavaScript loops.

## Problems Included
1. Print numbers from 1 to N.
2. Calculate the sum of numbers from 1 to N.
3. Display a multiplication table.
4. Print even numbers up to N.
5. Calculate the factorial of a number.

## Technologies Used
- HTML
- CSS
- JavaScript

## Concepts Learned
- For loops
- Conditional statements
- Variables and operators
- Arrays
- User input and output

## How to Run
1. Open assignment17.html in a web browser.
2. Select a coding problem.
3. Enter a whole number between 0 and 100.
4. Click the Solve Problem button.
5. View the result.
